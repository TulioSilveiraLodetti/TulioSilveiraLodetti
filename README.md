# Túlio Lodetti

Desenvolvedor full stack em formação — React, Java (Spring Boot), MySQL e Unity.

Construo sistemas web completos (front + back + banco) e também jogos 2D. Meu foco é entregar projetos que funcionam de ponta a ponta: login, API REST, deploy e interface pensada pro usuário.

| **Guarda-Vidas** | Sistema para postos de guarda-vidas: login (admin/operador), ocorrências e mapa dos postos | React · Java · MySQL |
| **Biblioteca SENAI** | Controle de salas, computadores e mapa ao vivo do laboratório | React · Java · MySQL |
